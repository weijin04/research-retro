# 示例边界

所有 `*.json` 和 fixtures 均为设计示例。带 `is_example: true` 的记录不得写入真实项目事实命名空间。预检请求使用合成文字；本包没有执行该请求。

`source_manifest.example.json` 描述本机接入配置建议，不表示已经扫描或获准外发全部内容。`task_proposal.json` 的数值仅展示有限资源合同，不是生产预算或工期估计。`decision_record.json` 的分布由人工构造，不代表真实 Jev 输出。

`jev_questions.json` 是待现场使用和改进的题目初稿；默认仅建议模式，不含通用采信阈值。模型无法从遗漏候选中选择正确答案，调用者需要保留候选扩展入口。
