# R2 验收依据

范围：本机模块化复盘产品；grephene 开发项目及 diffusion 指定快照切片。来源只读，独立后处理。下面的检查不是全项目物理结论认证，也不是独立盲测。

| 发布条件 | 实际实现与检查入口 |
|---|---|
| 旧索引、覆盖、未归属结果 | 8 张旧表原字段迁移；每个发现资产保留覆盖状态；`sources scan`、`query --indexes`、311 条原始待审候选及主题路由 |
| 源变化、定位、身份 | `tests/test_ingest.py` 的稳定快照、逐级安全打开、删除及变化检查；`test_provenance.py`、`test_runs.py` 的条件与实际输入恢复 |
| 承重关系深审 | grephene 梯度/能量参考/单调性、T13b 接触迁移、EA(Q)；diffusion 速度温度复算；各 case 有逐原件哈希、实际脚本输出、推导、竞争解释和不适用范围 |
| 来源独立性与循环 | `source_families` 保留所有路径、共同祖先、SCC；存储最小不动点不允许循环自证，重复报告不增加物理样本数 |
| 历史、分支、负知识 | 广域 1014 条有定位的重建记录；五轨历史未知不补写；实现失败、未验证、反证及工作处置分开；每条当前负知识有范围和重开条件 |
| 纠偏与中断 | `checks/verify_r2_recovery.py` 在真实数据库克隆上撤销梯度前提、逐个移除单调性反例、比较报告失效和无关结果；SQLite/blob 一致备份恢复；生产源不改 |
| 扩展后的依赖隔离 | `checks/verify_r2_entry_isolation.py` 对旧 EA 与 DLPNO、T13b、局部梯度及独立负知识进行真实克隆检查；失败的首次早到检查亦保留 |
| 增量、事务、旧结果 | 对象版本读集、政策版本、幂等键、原子事务和 outbox；旧字节可读；未变旧表不重解析；渲染失败不清除过期标记 |
| 历史指令、外发及恢复 | 输入作为数据；ZIP 只查目录且有限额；Jev 统一适配器拒绝未授权来源；实际 API 只使用固定合成材料 |
| 人类与新 agent 接手 | `HANDOFF_REVIEW.md` 与 `var/receipts/fresh_handoff*.json`；新上下文通过目录查结论、范围、反证和原件，未读材料不宣称已读 |

软件检查的完整实际输出在 `var/receipts/development_tests.log`；真实来源恢复、接手和科学执行回执分别保存，不能用单元测试数量替代后者。HTML 做过静态结构与安全输出检查，未宣称实际浏览器渲染验收。

报告当前采用的科学结论限于已完成的原件审计。旧全局机制排序、Marcus 门控/寿命、所有路径关闭、实验前体/产物身份仍是历史判定或未知，不能成为当前下游肯定前提。它们有具体再审入口；新的 DFT、MD、训练及集群作业需要另行授权。

R2 运行在用户授权的建设入口。它提供数据与语义边界；运行 worker 的环境强制隔离单独由 F1 的真实越界测试证明。
