# 分子入口 EA(Q) 原件审计

现有原件支持“指定 TMS 中性几何的垂直附电子吸热”，不支持把它扩大为有机叠氮在界面的所有 DEA 路径已排除。这个限制不构成 DEA 已成立的证据。PFPA 是不同对照对象，不能替代 TMS。

原判定原话及位置见 [原 case](entry_audit_case.json) 的 `original_claims`：RESEARCH_CONTROL.md 第 22 行是复合历史报告，其中 PhN3、CH3N3、CT 数值及其他分支未由本次核查背书。BRIEF/JOBS 是历史来源与文件状态解释线索；能量、几何与收敛状态回查实际输入输出。现存 wrapper 只解释当前保存代码的判定规则，不能证明历史运行时代码版本完全相同。

| 核查关系 | 实际结果 | 可采信范围 |
|---|---:|---|
| 旧 TMS r2SCAN 垂直 EA | −2.126641637 eV | 旧 −2.13 数值可复现；同一中性几何 |
| TMS 中性扫描 r=1.74 Å，TZVPD EA | +0.290847039 eV | 同几何电荷配对；不是界面捕获路径 |
| TMS 阴离子扫描首点 r=1.24 Å，TZVPD EA | +1.428435828 eV | 此几何相对中性扫描首点需 1.728140494 eV 中性形变能 |
| PFPA 中性扫描首点，TZVPD EA | +0.467425910 eV | 独立分子对照；不是 TMS |
| TMS 中性极小点 DLPNO 垂直 EA | −0.398232546 eV | 已完成的分子计算，有限方法与基组 |
| TMSN3 + e → TMSN− + N2 分离端点 | +0.017609081 eV | 电子能、真空电子零点；不是自由能或势垒 |

72 个 EA 均直接配对 144 个完成的 hybrid SP 输入输出，逐对校验电荷、自旋、方法和坐标；36 份保存扫描几何与对应 SP 输入吻合。公式为 EA(Q)=E0(Q)−E−(Q)。同一 Nα–Nβ 距离不代表同一 Q：TMS 首点的中性/阴离子扫描 NNN 角分别约 174.751°/133.523°。因此阴离子几何正 EA 不能抹去中性构象到达该几何的代价。1.24 Å 中性扫描首点是受约束参考，不冒充真正 FC 极小点。

最强竞争解释是：旧负 EA 对初始 TMS 几何仍然成立，沿中性形变能虽出现正 EA，但该形变及电子供体成本仍可能使实际入口不可达。本次保留这一解释，亦保留界面环境改变结果的可能；两者不能由孤立分子数据区分。有限片段电荷转移需计入供体 IP 和相互作用能；电子库表达中的 −μe 与真空零点必须一致，不能直接以真空附电子门槛比较相对费米能的热电子超额能量。

回查还发现三个必须保留的资格条件：TMS 第九中性扫描点未收敛，正常 SP 不补足父几何收敛；PFPA 当前中性扫描输出仅含被重跑覆盖的前三步，不能认证全部保存帧的松弛历史；PFPA 五个高层作业没有最终能量，只有 N2 完成，缺项不记零。A6 的“crossing”选择器实际选阴离子扫描首次 EA>0 点（两分子均首点），不是已定位的中性→阴离子路径交叉。

本次没有新增科研计算、执行原仓脚本或外发科研数据。369 个实际读取原件带哈希、行区间和快照入口，77 个分组按具体电荷配对及关系维护依赖；没有用 369 个来源合并成一个不可拆支持集。未审的其他有机入口保留历史降级/待核资格，不能写成已反驳。
